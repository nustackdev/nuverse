# nuverse

The extensions a [nuspace](https://github.com/nustackdev/nuspace) space offers out of the box: the Planes `+` creates and the Cells `/` inserts.

Apps in nuspace are Planes: data, seeded when created, with all their behavior in their cells.

It comes with nuspace, and nuspace finds it through the `nuspace.extensions` entry point. You don't import it yourself.

```
pip install nuspace
```

Part of the [nuverse](https://github.com/nustackdev/nuverse) monorepo, the std package every space ships with.
