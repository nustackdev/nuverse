# nuverse-log

[nulog](https://github.com/nustackdev/nulog) as a [nuspace](https://github.com/nustackdev/nuspace) extension: a Log plane `+` creates, for entries and metrics.

```
pip install nuverse-log
```

nuspace finds it on install through the `nuspace.extensions` entry point. You don't import it yourself.
